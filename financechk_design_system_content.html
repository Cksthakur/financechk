Line height + letter spacing rules
  • Display headings: line-height: 1.15 · letter-spacing: -0.03em — tight, editorial
  • UI headings (H2–H3): line-height: 1.35 · letter-spacing: -0.01em
  • Body text: line-height: 1.7 · no letter-spacing — maximum readability
  • Eyebrows / labels: letter-spacing: 0.08em · always text-transform: uppercase
  • Monospace numbers: letter-spacing: -0.04em — tighter than default mono for ₹ amounts
  • Never mix font families in a single text block — display for titles, body for everything else

Specific interaction animations
Result number update
When calculator inputs change → result number does NOT animate (jarring during slider drag). Instead: a subtle 80ms opacity pulse (0.6 → 1) on the result card confirms the value updated. Smooth, not distracting.
/* result-pulse keyframe */ @keyframes result-pulse { 0% { opacity: 0.6; } 100% { opacity: 1; } } .result-updated { animation: result-pulse 80ms var(--fc-ease-out); }
Comparison bar entry
Width animates from 0 to final value on mount. 400ms spring ease. Only plays once on first render — not on input change. Uses CSS animation, not JS.
ToolCard hover
transform: translateY(-2px) + shadow-md on hover. 150ms ease-out. Scale is intentionally absent — scale on small cards looks amateur on finance sites.
Chart draw (Recharts)
Set isAnimationActive={!prefersReducedMotion} on all Recharts components. Chart draws left-to-right, 600ms. If reduced motion: instant render.
Reduced motion implementation
/* globals.css */ @media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; } } /* React hook for JS animations */ const usePrefersReducedMotion = () => window.matchMedia('(prefers-reduced-motion: reduce)').matches;

Content below fold — mandatory sections (in order)
1
HowTo section (3–5 steps)
Marked up with HowTo schema. "Step 1: Enter your monthly take-home salary. Step 2: Enter your existing EMI obligations." Google can show this in rich results. Max 5 steps, each 1 sentence.
2
Formula section
The actual formula, explained plainly. Not academic — practical. "Banks use: Loan = (Net Salary × 55%) ÷ EMI per lakh." Include a worked example with real numbers. This is what builds trust and backlinks.
3
Contextual article (600–900 words)
Not just filler — genuinely answers the next question the user has. For eligibility calc: "Why does my employer's category matter?" Cite RBI guidelines directly.
4
FAQ accordion (5–7 questions)
Answers questions people actually search. Pull from "People also ask" in Google. Each answer 2–3 sentences. FAQPage JSON-LD injected automatically by FAQSection component.

Related tools cluster (4 links)
